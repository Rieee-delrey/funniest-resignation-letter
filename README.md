## What it does

`main.py` writes a single one-line resignation letter, in the voice of a retry loop that has had enough, to `/output/entry.txt`. The file holds exactly that one line, with no trailing newline.

## How to run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
